## 주차별 수업 정리

| 주차 | 수업 내용 |
| --- | --- |
| Week 1 | 수업 소개, Jupyter Notebook/Colab 사용법, Python 분석 환경 설정 |
| Week 2 | Python 기초 문법, 변수, 자료형, 리스트, 딕셔너리 |
| Week 3 | NumPy 배열 생성, 차원 확인, 인덱싱, 슬라이싱 |
| Week 4 | NumPy 배열 결합과 분리, 배열 형태 변환 |
| Week 5 | Matplotlib 선 그래프, 산점도, subplot |
| Week 6 | Pandas DataFrame 생성, 데이터 확인, 행과 열 선택, 기초 통계 |
| Week 7 | Titanic 데이터 탐색, 조건 필터링, 컬럼 선택 |
| Week 8 | Pandas 데이터 전처리, 정렬, 컬럼명 변경, 파일 입출력 |
| Week 9 | Matplotlib/Seaborn 데이터 분포 시각화, 변수 간 관계 시각화 |
| Week 10 | 다양한 데이터셋 시각화, 그래프 유형별 표현과 해석 |
| Week 11 | `groupby`, 집계, `merge`, 데이터 그룹화와 병합 |
| Week 12 | Pandas와 시각화 종합 실습 |
