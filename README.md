# 2026 Big Data Analysis Study

빅데이터 분석 프로그래밍 수업 내용을 주차별로 정리한 저장소입니다.  
Python 기초부터 NumPy, Pandas, 데이터 시각화까지 Jupyter Notebook으로 실습한 내용을 담고 있습니다.

## 사용 기술

- Python
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn

## 주차별 수업 정리

| 주차 | 수업 내용 |
| --- | --- |
| Week 1 | 수업 소개, Jupyter Notebook/Colab 사용법, Python 분석 환경 설정을 학습했습니다. |
| Week 2 | Python 기초 문법, 변수, 자료형, 리스트와 딕셔너리 같은 기본 자료구조를 실습했습니다. |
| Week 3 | NumPy 배열 생성, 차원 확인, 인덱싱, 슬라이싱 등 배열 처리 기초를 학습했습니다. |
| Week 4 | NumPy 배열 결합과 분리, 배열 형태 변환 등 다차원 배열 활용 방법을 실습했습니다. |
| Week 5 | Matplotlib을 사용해 선 그래프, 산점도, subplot 등 기본 시각화를 연습했습니다. |
| Week 6 | Pandas DataFrame 생성, 데이터 확인, 행과 열 선택, 기초 통계 확인을 학습했습니다. |
| Week 7 | Titanic 데이터 등을 활용해 조건 필터링, 컬럼 선택, 데이터 탐색을 실습했습니다. |
| Week 8 | Pandas를 이용한 데이터 전처리, 정렬, 컬럼명 변경, 파일 입출력을 연습했습니다. |
| Week 9 | Matplotlib과 Seaborn을 활용해 데이터 분포와 변수 간 관계를 시각화했습니다. |
| Week 10 | 다양한 데이터셋으로 시각화 실습을 반복하며 그래프 해석 방법을 익혔습니다. |
| Week 11 | `groupby`, 집계, `merge`를 활용한 데이터 그룹화와 병합을 학습했습니다. |
| Week 12 | 앞에서 배운 Pandas와 시각화 내용을 바탕으로 종합 실습을 진행했습니다. |

## 실행 방법

필요한 패키지를 설치한 뒤 Jupyter Notebook에서 원하는 주차 파일을 실행하면 됩니다.

```bash
pip install -r requirements.txt
jupyter notebook
```
